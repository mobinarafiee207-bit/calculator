# 🧮 Calculator

A simple and beautiful calculator built with HTML, CSS, and JavaScript

## ✨ Features

- ➕ Addition, Subtraction, Multiplication, Division
- 📊 Percentage calculation
- √ Square root
- ± Sign change (Positive/Negative)
- 💾 Memory (MR)
- 📜 Calculation history
- 📱 Responsive design
- ⌨️ Keyboard support
